# MetaRulesX Team Cards — React + Vite

## Run locally

1. Install Node.js (LTS) if it is not installed.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
```

Images are stored in `public/images`. Team details are in `src/App.jsx`, and each card is rendered by `src/components/TeamCard.jsx`.
